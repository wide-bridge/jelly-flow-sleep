# Jelly flow · 젤리 플로우

BetterSleep의 차분한 야간 분위기를 참고한 모바일 우선 숙면 루틴 웹앱입니다. 해파리의 부유감은 작은 브랜드 마크와 추상적인 물결로 표현했습니다. 이완 안내는 자연스러운 호흡, 얼굴·어깨·팔·다리 힘 놓기, 선택적인 심상, 음악 또는 고요한 쉼으로 이어집니다.

## 실행

### 단일 파일 버전

`standalone/Jelly-flow.html`에 두 곡의 음원과 CSS, JavaScript를 모두 포함했습니다(약 9.78 MiB). 파일 하나만 복사하면 됩니다. Chrome 또는 Edge에서 HTML 파일을 열어 사용합니다. 서버나 인터넷 연결이 필요하지 않으며 외부 웹폰트 대신 시스템 글꼴을 사용합니다.

기록은 HTML 파일 자체가 아닌 해당 브라우저의 저장소에 남습니다. 다른 컴퓨터로 옮길 때는 기록을 JSON으로 내보낸 뒤 가져오세요. 파일 위치/이름 변경 또는 브라우저 정책에 따라 기존 기록이 보이지 않을 수 있습니다. 기존 localhost 버전의 기록도 별도로 내보내고 가져와야 합니다.

다시 묶으려면 `node build-standalone.mjs`를 실행합니다. 포함된 두 음원이 원본과 바이트 단위로 일치하고, 기존 앱 코드가 그대로 보존되며, 외부 리소스 의존성이 제거되었음을 확인했습니다. 단일 파일 JavaScript 구문 검사도 통과했습니다. 내장 브라우저의 file URL 보안 정책으로 파일 직접 실행에 대한 브라우저 검증은 수행하지 못했습니다. 기존 서버 버전의 동작 검증 결과는 아래에 있습니다.

### 개발용 서버 버전

프로젝트 폴더에서 다음 명령을 실행합니다. Python 표준 라이브러리만 사용하며 별도 설치가 필요하지 않습니다.

```powershell
python server.py
```

브라우저에서 `http://127.0.0.1:8032`를 엽니다. 또는 `npm start`를 사용할 수 있습니다. `index.html`을 파일로 직접 열면 JavaScript 모듈이 차단될 수 있습니다.

서버는 이 컴퓨터의 루프백 주소에만 연결됩니다. MP3 탐색에 필요한 HTTP byte range를 지원합니다. 일반 `python -m http.server`에서는 일부 브라우저가 음원의 원하는 지점으로 이동하지 못하므로 제공한 서버를 사용하세요.

## 구현한 기능

- 오늘 밤 / 소리 / 기록, 모바일 하단 탐색과 미니 플레이어
- 상태 4개 × 시간 5·10·15분의 결정적인 추천 12개
- 단계를 건너뛰어도 원래 종료 시각 유지, 건너뛴 시간은 마지막 음악/쉼 단계로 연결
- 기상 목표 선택 및 남은 시간 안내
- 「힘을 놓고 고요함에 머물러요」와 「천천히 걷자」 두 곡 포함, 실제 MP3 재생
- 재생·일시정지·정지·구간 이동·이전·다음·한 곡 반복·목록 재생·음량
- 5·10·15·30·60분 음악 타이머, 루틴 중에는 루틴 종료 시각 우선
- 마지막 루틴 선택·곡·재생 위치·설정 복원. 새로고침 후 자동 재생하지 않음
- 즐겨찾기 및 즐겨찾기 필터
- 완료/중단 기록, 연결된 아침 기록 작성·수정·삭제
- JSON 내보내기/검증 후 가져오기, 교체/삭제 전 확인
- 음원 없음, 재생 거절, 파일 누락, 저장 차단, 손상된 데이터 처리
- 키보드 조작, 레이블, 네이티브 모달 포커스, 동작 줄이기 대응
- 지원 브라우저에서 미디어 세션과 선택적인 WebMCP 루틴 미리보기

## 파일

```text
dist/
  index.html          화면 구조
  style.css           남색·라벤더 디자인 및 반응형 레이아웃
  app.js              플레이어, 타이머, 화면, 기록 저장
  tracks.js           음악 목록
  routineContent.js   추천 규칙과 단계 안내
  audio/release-into-stillness.mp3
  audio/walk-slowly.mp3
server.py             로컬 미리보기 서버
tests/                주요 흐름 및 오류 상황 브라우저 검증
```

프로젝트 폴더명은 처음 생성한 `jellyfish-flow`를 유지하며, 실제 서비스 브랜드는 **Jelly flow · 젤리 플로우**입니다.

## 음악 추가 및 데이터

곡을 추가할 때는 MP3를 `dist/audio/`에 넣고 `dist/tracks.js`에 같은 형식의 객체를 추가합니다. ID는 영구 식별자로 유지하세요. 곡 목록은 데이터에서 자동으로 렌더링됩니다. 현재 음악 목록에는 「힘을 놓고 고요함에 머물러요」와 「천천히 걷자」 두 곡이 있습니다. 목록 확장 검증에 사용한 가상 곡은 실제 파일에 추가하지 않았습니다.

사용자 요청에 따라 두 MP3와 단일 HTML 파일을 비공개 GitHub 저장소에 포함합니다. 공개 배포 시에는 음원 권리와 공개 범위를 확인해야 합니다. 실제 음악 길이는 브라우저 메타데이터로 읽으며, 검증 환경에서 약 3분 11.6초입니다.

데이터는 `localStorage`의 `sleepApp:v1`에 저장됩니다. 브라우저 또는 접속 주소가 다르면 기록도 별개입니다. 비공개 모드나 사이트 데이터 삭제로 기록이 사라질 수 있어 내보내기를 제공합니다. 서버에 체감 기록이나 음원 파일을 업로드하는 API는 없습니다. 폰트는 Google Fonts를 불러오며 연결이 안 되면 시스템 글꼴을 사용합니다.

## 검증

2026-09-29, Windows Edge 기반 자동 브라우저 검증과 Codex 미리보기 확인을 수행했습니다.

- 12개 루틴의 총 시간과 같은 입력의 동일 결과
- 실제 음원의 메타데이터, 재생/일시정지, 구간 탐색, 음량, 반복, 단일 오디오 유지
- 타이머 만료 시 재생 정지와 무음 루틴 완료
- 새로고침 시 자동 재생 방지 및 종료된 루틴 복구
- 즐겨찾기와 아침 기록 유지, 수정/삭제, JSON 왕복, 잘못된 가져오기 거절
- 사용자 입력 HTML 실행 방지
- 재생 거절, MP3 404, 저장 차단, 손상된 JSON 보존
- 빈 음악 목록과 임시 3곡 목록: 긴 제목, 이전/다음 순환, 마지막 곡 후 연속 재생 정지
- 320px / 390px / 1440px에서 가로 넘침 없음, 화면 캡처 시각 점검
- Codex 브라우저의 실제 WebMCP 등록/정상 입력/잘못된 입력 거절

JavaScript 구문 확인: `npm run check`.

브라우저 테스트는 Playwright와 Edge가 필요합니다. 설치된 Playwright 경로를 `JELLY_PLAYWRIGHT_PATH`로 지정하거나 프로젝트에서 `playwright`를 찾을 수 있게 한 뒤, 서버 실행 상태에서 `node tests/browser-smoke.mjs`와 `node tests/browser-edge-cases.mjs`를 실행합니다. 테스트는 별도 브라우저 프로필을 사용하며 사용자 미리보기의 기록을 바꾸지 않습니다.

실제 iPhone Safari / Android Chrome 및 화면 잠금 상태의 장시간 재생은 아직 확인하지 않았습니다. 백그라운드에서 OS가 브라우저를 중지하면 정각에 음악 종료를 보장할 수 없으며, 다시 열었을 때 종료 시각으로 복구합니다. 계정·동기화·수면 단계 측정·나레이션·PWA는 이번 범위에 포함하지 않았습니다. 체감 기록은 진단이나 수면 측정값이 아닙니다.
